# 网页交互实验室

一个可直接在浏览器打开的原生 HTML / CSS / JavaScript 演示：把五种交互放在同一个实验台中，适合观察遮罩、透视、输入事件和 Canvas 粒子如何配合。它是交互原型，不是组件库或原站源码。

## 亮点

- 分层场景收合：背景遮罩收成胶囊，人物前景独立缩放。
- 弧形唱片轮播：支持拖动、滚轮、按钮和左右方向键。
- 五片玻璃独立倾斜：共享坐标内容被裁进不同面板，文字随接缝产生错位。
- 文件夹扇形展开：支持鼠标悬停、点击与键盘聚焦，卡片可以选中。
- 咖啡豆粒子扰动：Canvas 绘制形状，使用惯性、旋转与弹簧回归效果。
- 各效果带参数滑杆、重置、手动启动的自动演示和沉浸模式；支持减少动态效果偏好。

## 前置条件

运行只需近期桌面版 Chrome / Edge 等支持 Canvas 2D、Pointer Events、ResizeObserver、CSS 3D 变换及 SVG foreignObject 的浏览器。没有 npm 依赖、API Key、账号或模型服务。

可选：Python 3 用于本地静态服务；Node.js 22+ 用于静态自检。

## 安装与运行

下载仓库并解压，双击 `index.html`。保留 `assets/` 与页面的相对位置。

也可以在仓库根目录运行：

```sh
python -m http.server 8080 --bind 127.0.0.1
```

打开浏览器的 `http://127.0.0.1:8080`，结束时在终端按 Ctrl+C。服务仅供本机预览，不要直接用作公网生产服务器。

选择左侧效果后，按页面提示操作。镜头拉远可以滚动、拖动或调整进度；玻璃可以用指针或聚焦后的方向键调整。沉浸模式是页面内铺满效果，可按 Esc 退出，不是操作系统原生全屏。

## 目录结构

```text
index.html                         中文实验台与无障碍标签
style.css                          布局、遮罩、玻璃和响应式样式
app.js                             输入、状态、动画与粒子循环
assets/orchid-background-v2.png     场景背景层
assets/person-foreground-v2.png     透明人物前景层
scripts/check.mjs                  无依赖静态自检
```

## 验证方式

```sh
node scripts/check.mjs
```

自检验证 JavaScript 语法、页面 ID 唯一性、五个效果入口、必需资源引用和 PNG 结构；不会启动浏览器，不能替代交互验收。

本次整理已在桌面版 Edge 的 1440×1000、390×844 两种视口中完成 56 项浏览器断言，覆盖五个面板、场景收合与展开、轮播键盘操作、玻璃倾斜、文件夹选择、自动演示、沉浸退出、资源加载和减少动态效果；未发现控制台错误或页面横向溢出。这不是实体手机或跨浏览器兼容性保证。

手动验收：

1. 切换五个效果，确认只有一个面板显示，滑杆标签随效果改变。
2. 场景进度调至 100%，点击中心胶囊重新展开；调整过程中人物与背景独立变化。
3. 轮播通过下一张、上一张及左右方向键切换，重置回第一张。
4. 移动指针或用方向键改变玻璃倾角；文件夹打开后选择卡片，再重置。
5. 移动指针扰动粒子，检查自动演示的启动、停止、切换效果及沉浸模式 Esc 退出。
6. 在窄屏和系统“减少动态效果”模式下复查。

## 已知限制

- 这是五种效果的近似演示；不是原视频中网站的逐帧复刻，不能据此推断原站技术栈或触发方式。
- 玻璃效果由 CSS / SVG 模拟，不是真实光线追踪或折射渲染。
- 移动端采用响应式布局和 Pointer Events，但未在实体手机、多浏览器或辅助技术组合上全面验收；垂直触摸手势可能与页面滚动竞争。
- 粒子动力学是视觉近似，不是严格物理仿真；较弱设备可能掉帧。
- 交互脚本与页面 DOM 紧密绑定，移植到框架时需要拆分状态和生命周期。
- 展示用唱片、文件夹卡片和按钮文案不是完整音乐播放器、文件管理器或商业网站功能。
